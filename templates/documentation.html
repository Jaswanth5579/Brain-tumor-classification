Installation Guide

Prerequisites
  • Python 3.8 or higher
  • pip package manager
  • At least 4GB RAM
  • Modern web browser
Step-by-Step Installation
# 1. Clone or download the project
git clone <repository-url>

# 2. Navigate to project directory
cd brain-tumor-classification

# 3. Install required packages
pip install -r requirements.txt

# 4. Run the application
python app.py
Note: Make sure you have the trained model files (svm_model.pkl, logistic_model.pkl) in the project directory before running the application.

Usage Guide

Web Interface
  1. Start the Application: Run python app.py
  2. Open Browser: Navigate to http://localhost:5000
  3. Upload Image: Click "Choose File" or drag & drop an MRI image
  4. Get Results: Click "Classify Tumor" to get predictions
  5. View Results: See predictions from both SVM and Logistic Regression models
Supported Image Formats
  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • Maximum file size: 16MB

Model Details

SVM (Support Vector Machine)
  • Kernel: RBF (Radial Basis Function)
  • C Parameter: 10
  • Gamma: scale
  • Accuracy: ~95%
Logistic Regression
  • Solver: liblinear
  • Max Iterations: 1000
  • Random State: 42
  • Accuracy: ~92%
Image Preprocessing
  1. Convert to grayscale
  2. Resize to 200x200 pixels
  3. Flatten to 1D array (40,000 features)
  4. Normalize pixel values (0-1 range)
Classification Classes
  • 0: No Tumor
  • 1: Pituitary Tumor
  • 2: Glioma Tumor
  • 3: Meningioma Tumor

Testing

Run the built-in test suite:

Manual Testing
  1. Test with different image formats (JPEG, PNG)
  2. Test with various image sizes
  3. Test with corrupted or invalid files

Performance Testing
  • Average processing time: 2-5 seconds
  • Memory usage: ~500MB during processing
  • Concurrent users: Up to 10 (development server)

Troubleshooting

Common Issues

Solution: Ensure model files (svm_model.pkl, logistic_model.pkl) are in the project directory. Run the training script first: python brain_tumor.py

Solutions:
  • Check file size (max 16MB)
  • Ensure file format is supported (JPEG, PNG)
  • Check file permissions
  • Verify uploads directory exists

Solutions:
